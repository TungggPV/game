# Hero Skill Assets v2

Colorful skill sheet assets cut from the redesigned 4-hero infographic.

Recommended placement:

```text
public/assets/skills/
├── nova_blade/
├── crimson_flare/
├── volt_sentinel/
└── emerald_phantom/
```

Each hero folder contains:
- `icons/`: circular icons for J / K / L / U/I
- `cards/`: larger skill card crops and effect art crops
- `sheet/`: full column + header reference

Notes:
- `j_basic_attack_*` is for the normal attack (J), not a cooldown skill.
- Use `k_skill1_icon.png`, `l_skill2_icon.png`, and `u_ultimate_icon.png` for the skill bar.
- The effect art files are cropped from the poster and are useful for menu preview / documentation.
